OffDayKit — オフライン / Offline

ZIPをすべて展開し、index.htmlを現在のChromeまたはChromiumで開いてください。サーバー、インストール、アカウントは不要です。接続を切った状態で使えます。
1. 既存のUTF-8 .gan（GanttProject 3.4.3396 Beta VI）を選ぶ
2. 対象のリソースIDを明示的に選択し、曜日・毎週/隔週・基準の月曜日・有限の期間・除外日を設定する
3. プレビューで全候補と既存のカバーを確認し、確認チェックを入れて新しい .gan を保存する
確認JSONは全件、印刷は現在の確認ページです。レシピはリソースIDを含まず、毎回選び直します。

Extract the entire ZIP and open index.html in a current Chrome or Chromium browser. No server, installation or account is needed. It works disconnected.
1. Choose an existing UTF-8 .gan for GanttProject 3.4.3396 Beta VI
2. Explicitly choose resource IDs, weekdays, weekly/alternate-week cadence, anchor Monday, a finite inclusive window and excluded dates
3. Preview candidates and existing coverage, acknowledge the review, then save a new .gan
The JSON review includes all rows; print contains the current review page. Recipes omit resource IDs, which must be selected again.

This prepares native days-off records and their display. It does not schedule tasks, level resources, optimize workloads or promise compatibility with other versions. Existing vacation records and all bytes outside that section are preserved. Keep your original project backup.
Supported profile: years1900–2199, window up to366days ending no later than2199-12-30,100selectedresources,10000totalintervals,10MiBproject and64KiBrecipe.
